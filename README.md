# NitroLux Auto & Mobility — Fresh Complete React Demo

Premium dark luxury local-business website for:
- Car Wash
- Auto Workshop
- Detailing
- Rent-a-Car
- Service packages
- Booking CTA/modal

## Install
npm install

## Run
npm run dev

## Build
npm run build

The project uses remote Unsplash imagery and Google Fonts, so internet access is required for those assets.
